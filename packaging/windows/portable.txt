Plervo PDF portable mode

While this file sits next to plervo-pdf.exe, Plervo PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PlervoPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Plervo PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Plervo PDF and
%LOCALAPPDATA%\Plervo PDF) instead. If PlervoPDFData can't be written (for example on a read-only
drive), Plervo PDF says so and uses the per-user folders instead.
