# Plervo PDF icon

Contributor-original geometric P mark, shared with plervo.com. Ink #17251f and lime #cdf570. No Adobe or ArtCraft graphics.

SVG sources and generated platform icons are MIT OR Apache-2.0. Regenerate using `packaging/icons.sh` (resvg, iconutil and Python standard library); update ATTRIBUTION.toml hashes and run `cargo xtask assets --write`. Internal source asset filenames retain pdfcraft for build compatibility.
